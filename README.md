# microbit-montecharge-noir

Extension pédagogique micro:bit pour piloter un monte-charge
à trois niveaux (haut, milieu, bas).

## Capteurs
- fin de course haut
- fin de course milieu
- fin de course bas
- bouton appel haut
- bouton appel milieu
- bouton appel bas

## Actionneurs
- moteur monter / descendre / arrêter

Objectif pédagogique :
- masquer les broches
- utiliser un vocabulaire métier
- se concentrer sur la logique algorithmique



> Ouvrir cette page à [https://patriced-ops.github.io/microbit-montecharge-noir/](https://patriced-ops.github.io/microbit-montecharge-noir/)

## Utiliser comme extension

Ce dépôt peut être ajouté en tant qu'**extension** dans MakeCode.

* ouvrir [https://makecode.microbit.org/](https://makecode.microbit.org/)
* cliquez sur **Nouveau projet**
* cliquez sur **Extensions** dans le menu engrenage
* recherchez **https://github.com/patriced-ops/microbit-montecharge-noir** et importez

## Éditer ce projet

Éditer ce dépôt dans MakeCode.

* ouvrir [https://makecode.microbit.org/](https://makecode.microbit.org/)
* cliquez sur **Importer** puis cliquez sur **Importer l'URL **
* collez **https://github.com/patriced-ops/microbit-montecharge-noir** et cliquez sur importer
